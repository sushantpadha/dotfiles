# ncspot

<img src="https://raw.githubusercontent.com/hrkfdn/ncspot/main/images/screenshot.png" alt="ncspot" width="500">

Terminal Spotify client (ncurses UI). Considered, not currently used: [`lazyspotify`](../lazyspotify/README.md) is the daily driver instead.

Repo: [hrkfdn/ncspot](https://github.com/hrkfdn/ncspot).

## Install

```bash
cargo install ncspot
```

Requires a Rust toolchain (`rustup`) and a Spotify Premium account to play.

## Running

```bash
ncspot
```

Config and keybinds live at `~/.config/ncspot/config.toml`, not tracked in this repo. Populate manually if revisited.
